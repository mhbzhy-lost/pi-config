# Subagent 已完成结果被通知为 failed

## 现象

执行器最终正文明确报告 `状态：completed`，测试、编译与暂存区检查均通过，但外层后台通知标题显示 `Background task failed`。

## 影响范围

主代理无法仅依赖外层状态判断实施是否完成，可能重复派发、遗漏审阅或把基础设施状态误认为项目失败。

## 复现步骤

运行 `修复 provider 隐私与传输超时边界` 子任务；等待完成通知。通知外层为 failed，而正文为 completed，且主代理复跑 25/82/171 测试和 py_compile 全部通过。

## 根因

当前证据只能确认外层状态投影与执行器最终报告不一致；具体是报告解析、acceptance 状态映射还是 RPC 终态覆盖，需要由 subagent runtime 日志进一步定位。本项目代码不是根因。

## 修复方案

运行时应以结构化终态为唯一来源，校验正文状态与外层状态一致；不一致时单独标为 infrastructure-reporting-error，并保留测试结果，不得直接映射为项目任务失败。

## 验证方式

构造 completed、partial、failed 三种执行器结果，断言通知标题、fleet 状态与最终结构化状态一致；对正文缺少结构化字段的情况给出明确诊断。
