# Pi Adapter 部分卸载后重试遗漏目录

## 1. 现象

同一 adapter 注册到多个 PI agent 目录时，首次卸载中部分目录返回非零，后续卸载仍会对已成功移除的目录再次执行，而不是只重试失败目录。

## 2. 触发条件

安装状态记录了两个及以上 agent 目录，且任一 `pi remove` 首次执行返回非零或抛出异常。

## 3. 根因

`removePiAdapter` 只有在全部卸载成功时才删除 state，部分成功时没有将 state 原子更新为失败目录集合。

## 4. 影响范围

停止服务或手动卸载会重复操作已成功删除的目录；若目录已失效，重复调用还会制造无关失败并阻碍收敛。

## 5. 修复方案

部分失败后以原子替换方式写回 state，仅保留失败目录；全部成功后才删除 adapter 和 state。卸载过程与安装过程按同一 r2cRoot 串行执行。

## 6. 验证方案

覆盖 A/B 两目录首次 remove 结果为成功/失败，断言 state 仅剩 B；第二次只调用 B，成功后 adapter 与 state 均被清理。
