# Bug：Compact Tools 展开输出尾部多一行空行

## 1. 现象

部分 bash 等 tool 展开后，在最后一行实际输出与 `└─` 之间出现额外的 `│` 空行。

## 2. 影响

展开内容占用不必要的垂直空间，多个 tool 连续显示时边界松散，降低扫描效率。

## 3. 稳定复现

让 tool 返回以换行符结尾的文本，例如 `first\nsecond\n`，再调用展开渲染。输出稳定包含第三个空内容行。

## 4. 证据

`expandedBlock()` 直接执行 `text.split("\n")`。字符串末尾的换行会生成最后一个空字符串，而循环会把它渲染为 `│ `。截图中的空行位置与该分支一致。

## 5. 根因

展开渲染没有区分文本内部空行与末尾换行产生的空元素，错误地把传输格式中的尾部换行当成需要展示的内容行。

## 6. 修复与验证策略

增加一个以换行符结尾的展开输出测试，要求保留正文但不产生尾部 `│` 空行。渲染前仅移除末尾空行，保留正文内部空行；随后运行 renderer 测试和 Pi extension 加载验证。
