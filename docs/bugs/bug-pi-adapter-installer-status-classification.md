# Pi Adapter 安装器状态分类错误

## 现象
Pi 已启动但 `pi install` 返回非零退出码时，安装结果被记录为 skipped，而不是 failed。

## 触发条件
默认安装器调用系统 `pi` 命令，且该命令可执行但注册命令退出码为非零。

## 根因
默认执行器使用 `execFileSync`；非零退出码会抛出异常，调用方的通用异常处理将其统一归入 skipped，丢失了退出状态。

## 影响范围
安装结果无法区分“找不到 pi”与“Pi 注册失败”，降低失败诊断准确性；adapter 与 state 本身不受删除影响。

## 修复方案
改用返回状态的 `spawnSync`，保留依赖注入接口；`status === null` 归 skipped，非零数值归 failed。

## 验证方案
覆盖注入的 null、非零和零状态，覆盖已存在默认 agent 目录注册，并通过真实 PATH 中退出码 1 的 `pi` 脚本验证默认执行器分类。
