## 研究结论与范围依据

- Pi 官方 [v1.5.0 release](https://github.com/earendil-works/pi/releases/tag/v1.5.0)，2026-11-02；本次重点是 pi-schema 校验、pi-ai TypeBox 导出变化、流式/TUI 与 session 写失败修复。
- `pi-subagents@0.84.0` 是前轮官方 npm latest 查询结果，发布包 CHANGELOG 为 2026-10-28。本计划固定该精确版本，实施时重验 registry metadata/integrity，不自动追随之后的 latest。
- 本仓生成 workflow script，0.84.0 修复 [GHSA-6v8j-6w28-2w8r](https://github.com/nicobailon/pi-subagents/security/advisories/GHSA-6v8j-6w28-2w8r)，因此联合升级有直接依据；不是仅因 peer `*` 或 Pi 版本号推测必须升级。
- 0.81 将 root/subpath runtime exports 改为 bundle，child 仍用 unbundled 文件；公开 subpath 与 root 静态共享相同 registry/global keys，不据此假定真实 Host realm 已验证。
- 0.82 新增默认 workflow 自动恢复，正式配置为 `<agent-dir>/extensions/subagent/config.json` 顶层 `autoResume`，默认 true。本次显式 false；不能给 spawn 添加杜撰参数。
- 0.83.1 将 ceiling 查找统一为 `getSessionId()`。本仓 caller `extensions/subagent-runtime.ts` 仍用 sessionFile 优先的 lifecycleSessionId；只改传给 ceiling 的键，不更换 broker/completion/workspace 的身份体系。
- 上游 0.84 完成 run 的 30/90 天清理与 outputSchema 的额外补交回合如实记录为上游行为差异，不启用新产品能力，不把 upstream 历史长期保留视为本仓 durable proof。
- 详细证据：[subagents 研究](../investigations/2026-11-03-pi-subagents-upgrade-research.md)、[隔离与验收入口诊断](../investigations/2026-11-03-pi-1.5-upgrade-isolation.md)。历史 Pi 1.2.0/1.0.1 的接口变化不是本次新增，不重开旧任务。
